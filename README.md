# Arcadia

Catálogo público de juegos para navegador. Los juegos publicados están en `Aptos/`.

## Añadir un juego

1. Copia el archivo HTML aprobado dentro de `Aptos/`.
2. Añade su nombre de archivo y, opcionalmente, título y descripción en `juegos.json`.
3. Publica los cambios en GitHub. Arcadia mostrará el juego tras actualizarse el sitio.

Los archivos de `Local/` y `MisJuegos/` son personales y no forman parte de este catálogo.
